This is my first post! 🎉

You're reading a post that lives as a Markdown file in the repository. From now
on, I can write new posts straight from the **admin panel** at `/admin` — no
code editing required.

## A few things you can do in a post

- Write in **bold**, _italics_, and add [links](https://astro.build).
- Add lists, headings, quotes, and images.
- Insert code blocks:

```js
console.log('Hello from Raul\'s blog!');
```

> Publishing is as simple as writing the text and clicking **Publish**.

Thanks for stopping by — more soon.
